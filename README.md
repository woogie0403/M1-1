## 🚀 재현 실행 방법 (Reproducibility)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. KOBIS API 키 설정
`.env` 파일에 발급받은 KOBIS Open API 키를 입력합니다:
```text
KOBIS_API_KEY=your_kobis_api_key_here
```

### 3. 전체 파이프라인 단계별 실행
```bash
# [STEP 1] 일별 박스오피스 731일 수집 (약 5-10분 소요)
python collect_data.py

# [STEP 2] 데이터 정제 및 일별 시계열 집계 (EDA)
python clean_data.py

# [STEP 3] 시계열 분석 기법 (이동평균, 변화율, 요일/월별 통계) 계산
python time_series_analysis.py

# [STEP 4] 리포트용 시각화 3종 생성 (images/ 폴더)
python generate_visualizations.py

# [보너스 1] 시계열 심화: 추세/계절성/잔차 4단 분해 분석
python time_series_decomposition.py

# [보너스 2] Streamlit 인터랙티브 웹 대시보드 실행
streamlit run app.py
```

## 🎁 보너스 과제 상세 안내

### 1. [보너스 1] Streamlit 인터랙티브 웹 대시보드 (`app.py`)
- **실행 명령**: `streamlit run app.py`
- **핵심 기능**:
  - **사이드바 필터**: 연도(2024 vs 2025 vs 전체), 상세 날짜 슬라이더, 요일 멀티선택, 특정 영화 검색(`파묘`, `범죄도시4` 등).
  - **실시간 KPI 카드**: 총 관객수, 일평균 관객수, 주말 관객 비율, 최고 피크 영화 실시간 연산.
  - **인터랙티브 4대 탭**:
    1. 📈 시계열 추세 & 7일/30일 이동평균선
    2. 📅 요일별 평균 관객수 & 월별 누적 관객수 (계절성)
    3. 🏆 조건 내 관객수 TOP 10 피크 데이 및 1위 유지 영화 랭킹
    4. 💾 필터링된 데이터 미리보기 및 즉시 CSV 다운로드 버튼

### 2. [보너스 2] 시계열 분해(Decomposition) 심화 (`time_series_decomposition.py`)
- **분해 수식**: $Y(t) = Trend(t) + Seasonal(t) + Residual(t)$ (7일 주기 덧셈 모델)
- **주요 발견**:
  - **추세(Trend)**: 요일 노이즈를 걷어낸 순수 시장 흐름. 2024년 봄철(파묘-범죄도시4) 대형 산맥과 2025년 상반기 극심한 침체기 확인.
  - **계절성(Seasonal)**: 토요일(+21.3만), 일요일(+16.0만) 급등 ↔ 화요일(-12.5만) 급락의 칼같은 7일 주기 파동 입증.
  - **잔차(Residual)**: 2024-12-25 크리스마스(+94.6만 명), 2025-12-25(+82.6만 명), 2024-03-01 삼일절(+52.3만 명) 특수 스파이크 포착.

## 🎯 심사위원 예상 질문 & 완벽 방어 Q&A

**Q1. 이동평균 윈도우 크기를 왜 7일과 30일로 설정했나요?**
> **답변:** "영화 관객수는 금·토·일 주말에 폭증하고 월~목 평일에 급감하는 **'7일 주간 주기'**를 가집니다. 따라서 7일 이동평균을 써야 요일 노이즈가 완벽히 상쇄되어 순수한 신작 흥행의 단기 추세가 보입니다. 30일은 1개월 단위의 계절적 사이클(성수기/비수기)과 극장 시장의 중장기 모멘텀을 파악하기 위한 표준 윈도우로 선택했습니다."

**Q2. 크리스마스나 범죄도시4 개봉일 같은 100만 명 초과 데이터는 통계적 이상치(Outlier)인데, 왜 제거하지 않고 분석했나요?**
> **답변:** "머신러닝 예측 모델에서는 노이즈 제거를 위해 이상치를 자르기도 하지만, 본 과제의 목적은 **'데이터 기반 트렌드 분석'**입니다. 영화 시장에서 크리스마스 연휴와 천만 영화 개봉일은 단순 측정 오류가 아니라 **산업 전체의 매출을 좌우하는 가장 중요한 핵심 이벤트(Special Event)**입니다. 이를 제거하면 시장의 실상을 왜곡하므로, 이상치를 보존하고 오히려 '원인이 무엇인가'를 집중 조명하는 어노테이션 분석을 수행했습니다."

**Q3. AI(LLM)는 이 과제에서 구체적으로 어떻게 활용했고, 어떤 방식으로 검증했나요?**
> **답변:** "KOBIS API 731일 반복 호출 스크립트 작성과 Matplotlib 300 DPI 시각화 레이아웃 코딩에 AI를 활용해 개발 시간을 대폭 단축했습니다. 하지만 AI의 코드를 맹신하지 않고, **수집된 고유 날짜 수(731일)와 결측일(0건)을 전수 대조**했으며, 화요일 대비 수요일 반등률(+66.2%)과 연간 역성장률(-15.52%)을 **직접 콘솔 출력 통계와 1:1로 검증**했습니다. 특히 시각화에서 발생한 텍스트 겹침 버그를 직접 발견하고 오프셋을 재조정하여 신뢰도를 확보했습니다."
