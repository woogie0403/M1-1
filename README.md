## 4. 핵심 분석 결과 요약 (질문 3개 및 Fact-Why-Action)

### 📌 [질문 1] 2024년 vs 2025년 연간 총량 및 추세 비교
- **관찰 (Fact)**: 2024년 총 관객수 116,114,692명(일평균 31.7만 명)에서 2025년 98,093,333명(일평균 26.9만 명)으로 **전년 대비 -15.52%(-1,802만 명) 역성장**함. 30일 이동평균선 기준 2025년 상반기(2-5월)에 13.7만 명 선까지 급락.
- **원인 (Why - 가설)**: 2024년 상반기 연타석 천만 영화(파묘, 범죄도시4) 효과의 부재 및 티켓 가격(1.5만 원) 저항에 따른 OTT 대체 소비 고착화.
- **행동 (Action)**: 극장사는 비수기(3-5월) 특화관(IMAX/4DX) 패키지 프로모션을 도입하고, 배급사는 경쟁이 덜한 비수기 봄철 틈새 개봉을 추진해야 함.

### 📌 [질문 2] 요일별 쏠림 및 정책 효과 분석
- **관찰 (Fact)**: 화요일(16.7만 명)에 주간 최저점을 찍은 뒤 **수요일(27.8만 명)에 전일 대비 +66.2% 폭증**. 주말(토/일) 일평균은 48.0만 명으로 평일(21.9만 명) 대비 **2.19배**(주말 이틀이 전체의 46.2% 차지).
- **원인 (Why - 가설)**: 배급사들의 수요일 신작 개봉 관행과 매월 마지막 주 수요일 17-21시 관람료 50% 할인 '문화가 있는 날' 정책의 강력한 유인 효과.
- **행동 (Action)**: 화요일 좌석 가동률 개선을 위한 '화요 팝콘/포인트 더블 데이' 운영, 배급사는 개봉 전날 화요일 밤까지 SNS 바이럴을 집중시켜 수요일 오프닝 스코어 극대화.

### 📌 [질문 3] 이상치 피크 및 흥행 독과점 현상
- **관찰 (Fact)**: 2개년 단일 일자 최고 피크는 모두 **12월 25일 크리스마스**(2024년 151.8만 명, 2025년 134.8만 명). 특히 **2024-04-27(토)**은 1위 《범죄도시4》가 일별 총 관객 128.7만 명 중 121.9만 명을 동원하며 **점유율 94.74%를 싹쓸이 독점**.
- **원인 (Why - 가설)**: 메가 프랜차이즈의 스크린 독과점(80% 이상 상영관 배정) vs 크리스마스는 다양한 가족/연인 관객층의 장르 선호 분산으로 여러 영화가 파이를 공유.
- **행동 (Action)**: 영진위의 스크린 상한제 가이드라인 정책 근거로 활용 가능하며, 중소 배급사는 크리스마스/연말 대목에 2-3위 타깃 서브 장르(가족 애니메이션 등)로 동반 낙수효과를 노려야 함.

## 5. 환경 설정 및 단계별 재현 실행 가이드

### 5.1 필수 라이브러리 설치
Python 3.10 이상 환경(Windows / Mac / Linux)을 지원합니다:
```bash
pip install -r requirements.txt
```

### 5.2 API 키 환경변수 설정
`.env` 파일에 KOBIS Open API 키를 입력합니다:
```text
KOBIS_API_KEY=your_kobis_api_key_here
```

### 5.3 단계별 파이프라인 원클릭 실행
```bash
# 1단계: 2024-2025 일별 박스오피스 수집 (약 5-10분 소요, 결측일 자동 재시도)
python collect_data.py

# 2단계: 데이터 정제 및 일별 시계열 집계 (EDA)
python clean_data.py

# 3단계: 시계열 지표(7일/30일 MA, 변화율, 구간 통계) 계산
python time_series_analysis.py

# 4단계: 출판급 고해상도(300 DPI) 시각화 3종 생성 (images/ 폴더)
python generate_visualizations.py

# 보너스 1: 시계열 심화 4단 분해 (Trend-Seasonal-Resid) 분석
python time_series_decomposition.py

# 보너스 2: Streamlit 인터랙티브 웹 대시보드 실행
python -m streamlit run app.py
```

- **주요 기능**:
  - **다차원 인터랙티브 필터**: 연도(2024 vs 2025 vs 전체), 상세 날짜 슬라이더, 요일 멀티선택, 1위 영화 텍스트 검색(`파묘`, `범죄도시4` 등).
  - **실시간 KPI 카드**: 총 관객수, 일평균 관객수, 주말 쏠림 비율, 기간 내 최고 피크작 실시간 재계산.
  - **4대 탭 네비게이션**:
    1. 📈 시계열 추세 & 이동평균선(7일/30일 MA 반응형 차트)
    2. 📅 요일별 평균 관객수 & 월별 누적 관객수 (계절성)
    3. 🏆 조건 내 관객수 TOP 10 피크 일자 및 1위 유지 영화 순위
    4. 💾 필터링된 데이터프레임 미리보기 및 원클릭 CSV 다운로드 버튼

### 6.2 [보너스 2] 시계열 심화: 4단 분해 분석 (Decomposition)
- **분해 수식**: $Y(t) = \text{Trend}(t) + \text{Seasonal}(t) + \text{Residual}(t)$ (7일 주간 덧셈 모델)

#### 💡 '잔차(Residual)'와 '노이즈(Noise)'의 초간단 개념 풀이
- **잔차 (Residual, 남을 잔 殘 + 찌꺼기 차 差)**:
  - 수학적으로 **"기본 추세와 요일 효과를 계산하고 남은 찌꺼기(차이)"**입니다.
  - **쉽게 비유하자면**: *"요즘 영화관 평균 추세와 '토요일'이라는 요일 효과를 계산해 보면 오늘 45만 명 정도 올 것으로 예상되는데, 실제로 120만 명이 왔네? 그럼 예상보다 75만 명이나 더 많이 온 이 '설명할 수 없는 거대한 덤'은 도대체 어디서 생겼을까?"* 할 때 그 **예상치를 훌쩍 뛰어넘은 차이(+75만 명)**가 바로 잔차입니다.
- **노이즈 (Noise, 일상적 잡음)**:
  - 특별한 사건 없이 날씨가 조금 궂거나 일상적인 미세한 변덕으로 매일매일 오르락내리락하는 **'자잘한 먼지나 잔잔한 흔들림'**입니다. 평소 잔차는 0 근처에서 잔잔하게 흔들리는 노이즈 상태를 유지합니다.
- **거대한 잔차 스파이크 (Spike)의 의미**:
  - 잔차가 잔잔한 노이즈를 뚫고 **위로 로켓처럼 치솟았다면(+94.6만 명, +82.6만 명)**, 그것은 단순 잡음이 아니라 **"현실 세계에서 상상을 초월하는 초대형 이벤트(크리스마스 특수, 천만 영화 개봉 등)가 폭발했다!"**는 강력한 실증 신호입니다.

#### 📊 분해 결과 핵심 수치
- **추세 (Trend)**: 요일 노이즈를 걷어낸 순수 시장 흐름. 2024년 봄철(파묘-범죄도시4)의 웅장한 쌍봉 피크와 2025년 상반기(2-5월) 침체기 규명.
- **계절성 (Seasonal)**: 토요일(+21.3만), 일요일(+16.0만) 급등 ↔ 화요일(-12.5만) 급락의 7일 주기 파동 입증.
- **잔차 (Residual)**: 2024-12-25 크리스마스(+94.6만 명), 2025-12-25 크리스마스(+82.6만 명), 2024-03-01 삼일절(+52.3만 명) 특수 스파이크 포착.

#### 💼 실무 비즈니스 응용 방법 (이걸 보고 어떻게 써먹는가?)
1. **순수 이벤트 파워(특수)의 정밀 측정**:
   - 단순히 "크리스마스에 151만 명이 왔다"고 하면 151만 명 전부가 크리스마스 덕분인 줄 압니다.
   - 하지만 시계열 분해를 적용하면: *기본 수요일 평균(약 28만) + 12월 연말 추세(약 28만) = 약 56만 명*은 크리스마스가 아니어도 올 관객이었고, **진짜 크리스마스라는 브랜드가 만들어낸 순수 보너스 관객은 정확히 +94.6만 명**이라는 것을 과학적으로 발라낼 수 있습니다. (마케팅 투자 대비 효과 ROI 정밀 측정에 필수적)
2. **이상 징후 조기 감지 (Anomaly Detection)**:
   - 반대로 잔차가 마이너스(-)로 크게 주저앉는 날이 발생한다면, 날씨(태풍, 폭설)나 경쟁 엔터테인먼트(월드컵 경기, 대형 OTT 신작 공개) 등 극장 외적 위협 요인을 즉각 감지하고 조기 대응할 수 있습니다.
3. **극장 운영(인력 및 팝콘 재고)의 최적화**:
   - 평상시 주말은 '계절성(Seasonal)'에 맞춰 평일의 2배 인력을 배치하면 충분합니다.
   - 하지만 '잔차(Residual)가 폭증할 것으로 예상되는 날(크리스마스, 삼일절 연휴, 메가 IP 개봉일)'에는 평소 주말 대비 1.5배 이상의 아르바이트 인력을 추가 투입하고 팝콘 원자재를 3배 확보해야 극장 내 대기열 병목과 품절 사태를 막을 수 있습니다.

**Q4. AI(LLM)는 이 과제에서 구체적으로 어떻게 활용했고, 어떤 방식으로 검증했나요?**
